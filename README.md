## Sobre mim

Sou estudante de **Desenvolvimento de Sistemas na ETEC**, atualmente no 1º ano do curso.

Comecei a estudar programação recentemente e, desde então, venho conhecendo diferentes linguagens e tecnologias para entender melhor quais áreas do desenvolvimento mais me interessam.

Este GitHub reúne meus exercícios, projetos da escola, projetos pessoais e algumas das coisas que venho aprendendo durante o curso.
